# KINVINS.CD — Phase 8 : diaporama de 2 images par produit

- 2 images maximum par produit.
- Image 1 principale + Image 2.
- Fond blanc identique pour les deux images.
- Flèches gauche/droite.
- Deux points de navigation.
- Défilement automatique toutes les 4,5 secondes.
- Pause au survol.
- Diaporama également sur la fiche produit.
- Images stockées dans `public.product_images` et le bucket `product-images`.

Aucune nouvelle table SQL n'est requise si les migrations Produits + Images ont déjà été exécutées.
